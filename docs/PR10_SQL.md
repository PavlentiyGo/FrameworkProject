# Анализ SQL-запросов ПР10

Проверка выполнена 9 ноября 2026 года на Django 5.2.19, SQLite и исходных
трёх устройствах. Измерялись запросы чтения; записи рабочей базы не изменялись.

## Сравнение загрузки связей

```python
# Неоптимизированный учебный пример: один SELECT устройств + два на каждый объект.
[(d.name, d.room.name, d.condition.name) for d in Device.objects.all()]

# Используемая приложением загрузка: один SELECT с двумя INNER JOIN.
[(d.name, d.room.name, d.condition.name) for d in Device.objects.with_related()]
```

| Вариант | Запросов при N=3 |
|---|---|
| Обычное обращение к связям | 7 = 1 + 2N |
| `with_related()` / `select_related()` | 1 |

Загрузка через JOIN использовалась уже в ПР9 и сохранена при переносе
повторяющихся правил в собственные Manager и QuerySet.

## Реальные страницы

Режим `DEBUG=False`, анонимный Django Client с HTTP_HOST=localhost.

| Сценарий | SQL-запросов |
|---|---|
| Главная `/` | 1 |
| Список `/devices/` | 5 |
| Следующая страница `/devices/?page_size=2&page=2` | 5 |
| Поиск `/devices/search/?condition=исправно` | 5 |
| Статистика `/devices/statistics/` | 5 |
| Помещения `/rooms/` | 2 |
| Помещения без действующей техники `/rooms/available/` | 2 |
| Карточка устройства `/devices/3/` | 2 |
| Карточка помещения `/rooms/vannaia-3/` | 3 |

Для списка устройств пять запросов выполняют разные задачи:

1. Получение вариантов состояния в форме.
2. COUNT отфильтрованных устройств для пагинатора.
3. COUNT помещений для общей навигации (контекстный процессор).
4. Получение вариантов помещений в форме.
5. Выборка текущей страницы устройств вместе с помещениями и состояниями.

На второй странице SQL содержит `LIMIT 1 OFFSET 2` для исходных трёх устройств
и размера страницы 2. При фильтрации состояние добавляется в WHERE; сортировка
выполняется ORDER BY с дополнительным PK. При добавлении 12 тестовых устройств
в тестовой базе количество запросов списка осталось прежним.

Статистика выполняет агрегатный запрос, подсчёт для навигации, две группировки
и проекцию списка обслуживания. Проекция использует `annotate()` с `F()`
и `values()`; названия связанных объектов поступают в том же SELECT.
