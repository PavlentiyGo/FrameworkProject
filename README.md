# Сервис учёта бытовой техники

Консольное приложение для ведения домашнего или офисного реестра бытовой
техники. Проект позволяет хранить сведения об устройствах, отслеживать их
размещение и состояние, а также определять необходимость обслуживания.

Проект начат в ПР1, в ПР2 преобразован в модульное приложение, а в ПР3
переведён на объектно-ориентированную модель. Данные представлены объектами
классов `Device`, `Room` и `User`, которые загружаются из JSON-файлов.

## Объектная модель

- `Device` хранит сведения об устройстве и реализует изменение состояния,
  назначение помещения, проверку доступности и срока обслуживания;
- `Room` представляет помещение, в котором размещена техника;
- `User` представляет пользователя и проверяет пароль при авторизации.

Каждый объект реализует `__init__`, `__str__`, преобразование в словарь и
восстановление из словаря через метод класса `from_dict()`. Объект `Device`
содержит ссылку на объект `Room`. Поиск, фильтрация, сортировка и статистика
работают с коллекциями объектов и остаются отдельными функциями.

## Возможности

- авторизация владельца;
- просмотр и добавление устройств;
- поиск по названию, типу, производителю, модели и помещению;
- фильтрация по техническому состоянию;
- сортировка по названию, году покупки и стоимости;
- назначение устройства помещению;
- изменение технического состояния;
- проверка доступности к эксплуатации;
- определение необходимости обслуживания;
- снятие устройства с учёта;
- расчёт статистики по стоимости, возрасту, состояниям и помещениям;
- автоматическое сохранение изменений в JSON.

## Формат данных

Устройства, помещения и пользователи хранятся в JSON-файлах. При загрузке
каждая запись преобразуется в объект соответствующего класса. При сохранении
объекты преобразуются в словари методом `to_dict()`.

Запись устройства содержит идентификатор, название, тип, производителя,
модель, год и стоимость покупки, помещение, состояние и интервал обслуживания:

```json
{
  "id": 1,
  "name": "Холодильник на кухне",
  "device_type": "Холодильник",
  "manufacturer": "Atlant",
  "model": "ХМ-4425",
  "purchase_year": 2022,
  "price": 45990.5,
  "room_name": "Кухня",
  "condition": "требует обслуживания",
  "service_interval": 3
}
```

При запуске сначала создаются объекты `User` и `Room`, затем объекты `Device`
связываются с помещениями. После операций, изменяющих коллекцию, данные
сохраняются заново. Отсутствующий файл воспринимается как пустая коллекция,
а некорректный JSON обрабатывается без аварийного завершения программы.

## Требования и установка

- Python 3.10 или новее;
- pytest 8.0 или новее;
- flake8 7.0 или новее;
- pyright 1.1 или новее.

Установите инструменты разработки:

```bash
python3 -m pip install -r requirements.txt
```

Основное приложение использует только стандартную библиотеку Python.

## Запуск

```bash
python3 main.py
```

Демонстрационная учётная запись:

- логин: `owner@example.com`;
- пароль: `home2026`.

## Тестирование

```bash
pytest
```

Тесты проверяют создание объектов, методы и строковое представление классов,
взаимодействие устройств с помещениями, авторизацию, операции над коллекциями,
JSON-преобразование и обработку пользовательского ввода.

## Проверка качества кода

```bash
flake8
pyright
```
`flake8` проверяет оформление, а `pyright` — типы в исходном коде.
