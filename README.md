# Сервис учета бытовой техники

## Назначение

Сервис предназначен для ведения учета бытовой техники в доме, квартире или офисе. Он помогает хранить сведения об устройствах, отслеживать их размещение и текущее состояние, а также своевременно выявлять технику, требующую обслуживания или ремонта.

## Целевая аудитория

Сервис ориентирован на частных пользователей, семьи, владельцев недвижимости и сотрудников небольших организаций, которым необходимо систематизировать информацию об имеющейся бытовой технике.

## Предметная область

Предметная область включает учет бытовых устройств, их распределение по помещениям и контроль технического состояния. Пользователь может добавлять технику, указывать место ее размещения и изменять состояние устройства в процессе эксплуатации.

## Основные сущности

- **Пользователь** — владелец учетной записи, который управляет данными о бытовой технике.
- **Устройство** — единица бытовой техники с названием, типом, производителем, моделью и датой приобретения.
- **Помещение** — место размещения устройства, например кухня, гостиная, спальня или офис.
- **Состояние** — текущий статус устройства, например исправно, требует обслуживания, находится в ремонте или списано.

## Основные функции

- регистрация и авторизация пользователей;
- добавление, просмотр, редактирование и удаление устройств;
- создание и редактирование помещений;
- распределение устройств по помещениям;
- изменение и отслеживание состояния техники;
- поиск и фильтрация устройств по типу, помещению и состоянию;
- просмотр списка техники, требующей обслуживания или ремонта.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация системы регистрации и авторизации пользователей;
- разработка API;
- добавление напоминаний о техническом обслуживании;
- контейнеризация приложения;
- настройка CI/CD.

## Запуск начального сценария

В файле `main.py` реализован сценарий постановки бытового устройства на учет. Он включает авторизацию пользователя, добавление и просмотр устройства, его распределение по помещению, изменение состояния и проверку необходимости технического обслуживания.

Для запуска выполните команду:

```bash
python3 main.py
```
